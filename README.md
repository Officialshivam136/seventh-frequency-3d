# The Seventh Frequency 3D

A short playable 3D scene set in Neo-Mumbai, 2150. You are Detective Aryan Rao, tracking a strange signal from the street down into the city's underworld.

## Play

Open `index.html` in a browser, or run `node serve.js` and visit http://localhost:8377.

Controls: `W` `A` `S` `D` or arrow keys to move, `Shift` to run, `E` to interact, `M` to mute, `R` to replay after the ending.
